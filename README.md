# Endless Runner

Endless Runner is a small side-scrolling game made in Godot 4. You run, jump, duck, grab coins, and try to stay alive a little longer than last time. It is a quick boredom killer: easy to start, but still tempting enough for one more run.

## Play

Open the project in Godot 4.5 or newer and run `res://scenes/main.tscn`.

Controls:
- `Space` / `W` / `Up`: jump
- `S` / `Down` / `Ctrl`: duck
- Jump again in the air: double jump
